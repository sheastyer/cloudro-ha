# Vendored copy

This is a vendored copy of the `cloudro-ble` library (canonical source:
`../../../cloudro-ble/`). It is bundled so the integration installs via HACS
without a separate PyPI release. Keep it in sync with the canonical package; do
not edit here directly. `bleak` and `bleak-retry-connector` are provided by Home
Assistant's Bluetooth integration, so they are not listed as requirements.
